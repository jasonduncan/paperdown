What kind of document polish should paperdown optimize first?

These are product directions, not final pixel-perfect themes. Pick the one that feels like the best next step for making Markdown output feel like a real document.

report
Project Notes
Clear title page, restrained typography, strong tables and code blocks.

A. Classic Report

Professional and quiet. Better title pages, cleaner spacing, stronger headers, and more trustworthy-looking PDFs.

compiled edition
Collection
Cover page, table of contents, section-opening rhythm, running headers.

B. Compiled Publication

Feels authored, not exported. Cover page, section openers, and more visible structure for multi-file PDFs.

Meeting Brief
Larger type, wider spacing, stronger contrast, clearer hierarchy.

C. Accessible Handout

Optimized for readability first: bigger type, more whitespace, better contrast, less dense layouts.
